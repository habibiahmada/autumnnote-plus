## Summary

An internal cleanup release. The link, code and table tooltips now share one base class with the image and video tooltips, which makes the full builds slightly lighter. Behaviour, options, events and the API are the same as 4.3.0.

## Highlights

- The link, code and table tooltips share `BaseMediaTooltip`, so all five tooltips now position, time and tear down the same way. About 220 source lines are removed.
- The full builds are 0.2 KiB gzip lighter (UMD/CDN 95.2 KiB, ES 99.8 KiB).

## Added

None.

## Changed

- **The link, code and table tooltips share `BaseMediaTooltip`**, as the image and video tooltips already did (e1d4920, #18, #19).
  - Each tooltip kept its own copy of the button factory, show/hide timers, positioning and teardown. Those copies are removed.
  - Each tooltip now passes its delays and placement to the base, so timing and position are unchanged.
  - Internal only: the `_activeAnchor`, `_activePre` and `_activeTable` fields are now `_active`.
- **The CI audit ignores GHSA-fc5q-39xc-vjpf** (picomatch <=4.0.7, ReDoS through repeated extglobs) (f693ced).
  - No patched picomatch exists yet.
  - picomatch is reached only through dev tooling (`@vitest/browser > @vitest/mocker > vite`), never at runtime.
  - Other high advisories still fail the audit.
